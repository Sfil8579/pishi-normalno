# Правила сообщества

Обсуждайте тексты, правила и код, а не личность автора. Аргументируйте примерами и контрпримерами. Не публикуйте чужие приватные тексты без разрешения. Не используйте проект для травли, определения личности автора или бездоказательного обвинения в применении AI.

Мейнтейнер может скрыть или удалить материал, который нарушает эти правила, раскрывает приватные данные или создает риск для участников.
