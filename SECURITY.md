# Безопасность

## Поддерживаемая версия

Исправления безопасности выпускаются для последней стабильной major-версии.

## Как сообщить о проблеме

Не публикуйте секреты, приватные тексты или уязвимость с готовым сценарием эксплуатации в открытом issue. Отправьте приватный GitHub Security Advisory через вкладку Security репозитория.

Укажите версию, платформу, команду воспроизведения, ожидаемое и фактическое поведение. Удалите API-ключи, токены, персональные данные и закрытые тексты.

## Модель угроз

CLI работает локально и не отправляет текст по сети. Сетевой доступ нужен только инсталляторам для загрузки релиза. Инсталляторы сверяют SHA256 архива, проверяют структуру и не перезаписывают установку без явного флага обновления.
