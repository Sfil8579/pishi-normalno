# Как участвовать

Спасибо за помощь русскому тексту.

## Предложить новый паттерн

Каждый паттерн должен содержать:

1. Реальный плохой пример без приватных данных.
2. Объяснение проблемы именно для русского языка или выбранного жанра.
3. Один минимальный хороший вариант.
4. Не меньше двух контрпримеров, которые нельзя ломать.
5. Уровень сигнала: `error`, `warning` или `info`.
6. Регрессионный тест, если проверку можно выполнить детерминированно.

Отдельное слово редко является достаточным сигналом. Предпочтительны составные признаки: синтаксис, соседние фразы, жанр, изменение относительно исходника и нарушение смысловой связи.

## Локальная проверка

```bash
python -m pip install -e .[dev]
python -m unittest discover -s tests -v
python tools/validate_repo.py
ruff check .
mypy skills/pishi-normalno/scripts tools tests
```

## Правила изменений

- Не добавлять намеренные ошибки, сленг или метафоры по квоте.
- Не выдавать эвристику за определение AI-авторства.
- Не добавлять факты и обещания в примеры без источника.
- Не использовать локальные абсолютные пути и приватные данные.
- Не менять `.aislop/config.yaml` ради прохождения проверки.
- Не добавлять README, changelog или release-документы внутрь skill folder.
- Сохранять обратную совместимость CLI в пределах major-версии.

## Pull request

В описании укажите проблему, принцип решения, тесты, ложные срабатывания и влияние на существующие тексты. Если пример взят у реального автора, подтвердите разрешение на публикацию или обезличьте его.
